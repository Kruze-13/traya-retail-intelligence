# KPI Dictionary

This document defines the primary metrics used in the Traya Retail Intelligence portfolio project.

> All published portfolio data is synthetic / fabricated.

| KPI | Definition | Business interpretation |
|---|---|---|
| Walk-ins | Total shoppers observed at an outlet during the reporting period | Total shopper traffic available to the promoter |
| Relevant Shoppers | Shoppers matching the target category / consumer profile | Indicates whether the outlet attracts the right audience |
| Category Shopper % | Relevant Shoppers / Walk-ins | Measures audience relevance of the outlet |
| Interactions | Relevant shoppers actively engaged by the promoter | Promoter engagement volume |
| Interaction Rate | Interactions / Relevant Shoppers | Measures promoter ability to engage available relevant shoppers |
| Samples | Product samples / trials delivered | Trial-generation activity |
| Sampling Rate | Samples / Interactions | Measures movement from engagement to trial |
| Buyers | Interacted shoppers who purchased | Conversion output |
| Conversion | Buyers / Interactions | Measures effectiveness of promoter interaction |
| Offtake | Units / volume sold from the outlet | Core sales output |
| Offtake / Buyer | Offtake / Buyers | Average purchase intensity among buyers |
| Mandays | One promoter working one outlet on one working day | Deployment / productivity denominator |
| Offtake / Manday | Offtake / Mandays | Promoter productivity |
| Stockout Intensity | Stockout observations / eligible SKU-outlet-days | Frequency / severity of availability failure |
| Availability % | Available SKU-outlet-days / eligible SKU-outlet-days | Product availability health |
| Opportunity | Composite business signal based on relevance, conversion, demand and availability | Used to prioritise stores for action |

## Diagnostic Logic

A strong retail-performance diagnosis should distinguish four broad causes:

1. **Low traffic / low relevance** — the outlet may not attract enough target shoppers.
2. **Low engagement** — promoter execution may be weak.
3. **Low conversion** — shopper engagement is not translating into purchase.
4. **Low availability** — demand exists, but inventory constrains sales.

This prevents the business from treating every low-offtake outlet the same way.
